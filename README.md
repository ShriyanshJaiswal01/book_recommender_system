# Book Recommender System

A content-based and collaborative book recommendation web app built with Flask, Pandas, and scikit-learn.

##  Project Overview

This project provides a recommendation engine that suggests similar books when a user enters a book name. It is built from publicly available book and rating datasets and exposes a simple web interface for usage.

Key features:
- Displays top popular books on the home page (based on average rating and number of ratings)
- Takes user input and recommends 5 similar books
- Uses cosine similarity on a user-book rating pivot matrix
- Saves preprocessed data in pickle files for low latency

##  Repository Structure

- `app.py`: Flask application logic and route definitions
- `python.py`: data processing, model building, and pickling workflow
- `requirements.txt`: python dependencies
- `dataset/`: source input CSV files
  - `Books.csv/Books.csv`
  - `Ratings.csv/Ratings.csv`
  - `Users.csv/Users.csv`
- `templates/`: Flask HTML templates
  - `index.html`
  - `recommend.html`
- `popular.pkl`, `pt.pkl`, `books.pkl`, `similarity_score.pkl`: serialized data model files (generated by `python.py`)

##  Prerequisites

- Python 3.8+ (works well with 3.10/3.11)
- pip

##  Installation

1. Clone the repository:

```bash
git clone https://github.com/<your-username>/book_recommender_system.git
cd book_recommender_system
```

2. Create a virtual environment (recommended):

```bash
python -m venv venv
venv\Scripts\activate  # Windows
source venv/bin/activate  # macOS/Linux
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. (Optional) Download NLTK data (already inside app.py but can be done explicitly):

```python
import nltk
nltk.download('punkt')
nltk.download('stopwords')
```

##  Data Processing & Model Preparation

Generate required pickle files by running `python.py` once:

```bash
python python.py
```

- `popular.pkl`: DataFrame with top books for landing page
- `pt.pkl`: pivot matrix of books vs users
- `books.pkl`: original books DataFrame
- `similarity_score.pkl`: cosine similarity matrix for books

##  Run the Flask App

```bash
python app.py
```

Then open `http://127.0.0.1:5000` in your browser.

##  Usage

1. Home page shows popular books with rating and vote count.
2. Click "Recommend" and enter a known book title exactly as it appears in dataset.
3. App returns 5 nearest neighbor book recommendations with cover image and author.

##  How it Works

- `python.py` loads `Books.csv`, `Ratings.csv`, `Users.csv`.
- Filters users with > 200 ratings and books with >= 50 ratings.
- Creates `pt` pivot table (books × user ratings) and fills missing values with 0.
- Computes cosine similarity between books using `sklearn.metrics.pairwise.cosine_similarity`.
- `app.py` takes input title, finds index in pivot table, sorts similarity values, and returns top 5.

##  Notes

- Input is case-sensitive and must match exactly a book title in the dataset.
- Add validation in `app.py` to handle missing titles and avoid exceptions.
